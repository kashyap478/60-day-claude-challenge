**I gave the AI two versions of the same request:**

**1. Without Context Prompt (Generic)**

This prompt doesn't tell the AI who you are.

Example:

Create an image of a 30-day learning roadmap for AI and Data. Include weekly milestones, daily tasks, resources, projects, and the final outcome. Make it practical, beginner-friendly, and visually appealing.

Output:

AI Basics
Python Basics
SQL Basics
ML Basics
Generic projects
Suitable for anyone starting AI

**2. With Context Prompt (Personalized)**


This prompt gives AI information about your current situation, so it can customize the roadmap.

Example:

Create an image of a 30-day AI & Data job-switch roadmap.

Context:

Current Role: Project Manager in Market Research
Experience: 1 year 7 months
Current Skills: Python, Machine Learning, Power BI, Excel, GitHub, Jupyter, VS Code
Goal: Switch into AI/Data with an 8–10 LPA package
Available Time: 3 hours/day
Experience Level: Intermediate
Preferred Learning Style: Videos, Reading, and Projects

Include weekly milestones, learning resources, projects, interview preparation, and the final career outcome. Make it modern, minimal, and career-focused.

Output:

Skips basic Python because you already know it.
Focuses on strengthening ML and AI concepts.
Includes portfolio building and GitHub.
Adds interview preparation.
Ends with "AI/Data Analyst • AI Engineer • 8–10 LPA Ready."
Tailored to your available 3-hour daily schedule.
Simple way to remember
Without Context = "What should someone learn?"
→ General learning roadmap.
With Context = "What should I learn based on my current profile?"
→ Personalized career roadmap.
